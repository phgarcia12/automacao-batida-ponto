🚀 PASSO 1: INSTALAR PYTHON (se não tiver)

  1. Acesse: https://www.python.org/downloads/
  2. Baixe a versão mais recente (3.11+)
  3. Execute o instalador
  4. ✅ MARQUE: "Add Python to PATH"
  5. Clique em "Install Now"
  6. Feche o instalador

═══════════════════════════════════════════════════════════════════

🔧 PASSO 2: CONFIGURAR TAREFAS AGENDADAS

  1. Abra PowerShell como Administrador:
     - Windows + X
     - Selecione "Terminal do Windows (Admin)"
     ou
     - Clique direito no PowerShell e "Executar como administrador"

  2. Execute este comando:

     cd C:\Users\paulo.garcia\Desktop\Repos\automao-batida-ponto
     .\configurar_agendador.ps1

  3. Aguarde a instalação das dependências (Selenium, etc)
  4. Veja a confirmação: "✅ CONFIGURAÇÃO COMPLETA!"

═══════════════════════════════════════════════════════════════════

✅ PASSO 3: VERIFICAR INSTALAÇÃO

  1. Abra "Agendador de Tarefas" (Task Scheduler):
     - Pressione Windows + R
     - Digite: taskschd.msc
     - Pressione Enter

  2. Procure por "BatidaPonto_" na lista:
     ✓ BatidaPonto_0825  (08:25)
     ✓ BatidaPonto_1200  (12:00)
     ✓ BatidaPonto_1325  (13:25)
