================================================================================
                           POSSÍVEIS PROBLEMAS
================================================================================

PROBLEMA: "Geolocalização bloqueada"
SOLUÇÃO:
  - Conceder permissão de geolocalização no navegador
  - Configurar coordenadas no Playwright/Selenium
  - Exemplo: geolocation: { latitude: -23.5505, longitude: -46.6333 }

PROBLEMA: "CAPTCHA aparecendo"
SOLUÇÃO:
  - Usar serviço de CAPTCHA solving
  - Implementar delays entre ações
  - Adicionar headers realistas

PROBLEMA: "Sessão sendo bloqueada"
SOLUÇÃO:
  - Implementar anti-detecção (stealth plugins)
  - Usar User-Agent realista
  - Adicionar comportamento humano (delays, mousemove)

PROBLEMA: "Campo não encontrado"
SOLUÇÃO:
  - Aguardar carregamento completo da página
  - Inspecionar com DevTools (F12) no navegador
  - Verificar se JavaScript está habilitado
